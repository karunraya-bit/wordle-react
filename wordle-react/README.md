# Wordle Game Using React

## Project Description

This project is a Wordle-style word guessing game developed using React.
Players attempt to discover a hidden five-letter word within six guesses.

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite

## Main Features

- Six rows with five tiles per row
- Physical keyboard input
- Clickable virtual keyboard
- Backspace and Enter functionality
- Green, yellow, and gray letter evaluation
- Duplicate-letter handling
- Keyboard colour synchronisation
- Win and loss conditions
- Game-over modal
- Play Again functionality

## Installation

Clone or download the project and open its directory in the terminal.

Install the dependencies:

npm install

## Run the Application

npm run dev

Open the local address displayed in the terminal.

## Production Build

npm run build
